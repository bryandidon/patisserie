# Bryan Didon – Haute Pâtisserie

Site vitrine de **Bryan Didon**, artisan en haute pâtisserie.

## À propos

Ce site présente l'univers, les créations et le savoir-faire de Bryan Didon :

- **L'artisan** : parcours, philosophie et passion du métier
- **Les créations** : entremets, tartes, viennoiseries et pièces d'exception
- **Les événements** : pâtisseries sur mesure pour mariages, anniversaires et réceptions
- **Contact** : informations pratiques et prise de commande
